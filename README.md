# Lịch & brief content fanpage Ninemila

Trang web: https://kigogroupvn-dot.github.io/lich-content-ninemila/

## Sửa nội dung

Mọi nội dung (brief, tình trạng, link, ảnh bìa) nằm trong Google Sheet, mở bằng nút **"Mở Google Sheet"** trên trang.
Sửa trong Sheet xong, tải lại trang web là thấy (khoảng 1 phút).

- **Tình trạng:** bấm ô cột Tình trạng, chọn từ danh sách.
- **Link media / Link bài đã đăng:** dán link vào cột tương ứng.
- **Brief:** bấm đúp vào ô để sửa; xuống dòng trong ô bằng Ctrl + Enter.
- **Ảnh bìa / ảnh nền:** tab *Cài đặt*, dán link ảnh Google Drive (chia sẻ: Bất kỳ ai có đường liên kết).
- Không đổi tên các tab (Bài đăng, Tuần, Cài đặt) và không đổi chữ ở hàng tiêu đề.

## Đổi sang Google Sheet khác

Sửa link trong file `config.js`.

## Các file

- `index.html`: trang web
- `config.js`: link Google Sheet
- `data.js`: bản lưu sẵn, chỉ dùng khi không tải được Sheet
- `assets/`: logo và ảnh mặc định
- `robots.txt` + thẻ noindex: chặn Google tìm thấy trang
